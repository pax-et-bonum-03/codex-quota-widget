# 使用说明 · User guide

[中文](#中文) · [English](#english)

## 中文

本工具面向 ChatGPT Plus 用户的 Codex 工作流深度定制。

当前版本：1.4.7。收起态使用两片切角装甲，百分比突出、标签降低字重；展开保留橙红大仪表和圆角卡片，两张 token 卡片统一尺寸和排版。支持拖动移动、位置记忆与一键复原，默认位于屏幕顶部居中。

从发布包双击 `Start.cmd` 安装并启动，或在安装后双击 `%LOCALAPPDATA%/CodexQuotaWidget/app/CodexQuotaWidget.exe`。工具常驻主屏幕顶部。收起后只显示 5h 和周额度的**剩余百分比**以及各自的时间：**5h 仅时分，周额度保留月日和时分**，不显示“重置”前缀；不显示徽标、北京标签、装饰灯带或其他说明文字。所有重置时间均为北京时间，悬停时间文本可查看含年份和秒的完整时间。收起条使用内嵌的「未来荧黑 / Glow Sans SC」，百分比为 SemiBold，标签和时间为 Normal；百分比比标签更大、更亮。长译文会先缩小标签，必要时省略标签以保留比例，悬停可看完整内容。无需安装系统字体，字体授权随包保留在 `Fonts/OFL-GlowSans.txt`。

鼠标移入展开，移开约 0.28 秒后收起。窗口尺寸和位置一次同步到目标，淡入及背景层动效在固定位置内执行，避免逐帧调整系统窗口带来的抖动。收起尺寸为 270 × 50，展开尺寸为 584 × 390，单位为逻辑像素。展开可查看额度、倒计时、重置时间、今日 token 和累计 token。周额度保留小圆环和数字，去掉重复横条；今日和累计 token 的标题、数值与说明分别对齐，数值使用相同字号，“尚未更新”采用较小的状态文字。

每次展开立即显示当前额度，只有已知额度实际变化时才平滑过渡。文字位置固定，鼠标视差仅影响背景装甲和光效；装饰圆弧小幅摆动，呼吸光降低幅度。扫光随实际刷新运行一次；边缘用颜色提示刷新、低额度或读取失败，不作为百分比进度。剩余不高于 20% 时对应边缘变红，这是本工具的显示阈值。循环装饰只在展开时运行，收起后停止，跟随 Windows 的动画开关；窗口不会自动抢走当前软件的焦点。

每分钟刷新一次。网络故障时保留上次数据，在展开面板底部和提示中显示错误及上次更新时间。鼠标停留在数值上可查看完整数值和统计说明。

### 移动与复原

按住窗口文字或背景上的鼠标左键拖动即可移动；刷新、菜单和复原按钮正常执行点击。移动后展开和收起围绕所选位置进行，不会回到屏幕中心。靠近屏幕下沿时向上展开，屏幕边缘会限制窗口位置以保持可见。移动不会抢走当前软件的焦点。

展开面板右上角的向上箭头按钮可一键「恢复顶部居中」。右键悬浮条或系统托盘图标也能选择同一操作；也可在窗口文字或背景上双击复原。复原后回到主屏幕顶部居中的收起状态。

移动位置保存在 `%LOCALAPPDATA%/CodexQuotaWidget/data/position.json`，下次启动恢复；复原会清除保存的位置。显示器配置变化时自动将位置限制到可用屏幕。用户数据目录不可写时仍可拖动和复原，本次位置不会保存。

### 界面语言

右键悬浮条或托盘图标，进入「语言 / Language」，可选择简体中文、繁體中文或 English。菜单、提示、倒计时、状态信息与展开面板会立即切换，下次启动保留选择。

通过「语言 → 安装语言包…」导入 JSON 文件即可添加语言，无需重新编译。已安装包保存在用户数据目录的 `Languages` 文件夹，语言设置保存在同一目录的 `settings.json`；升级时保留这两处以及 `position.json`。新版本增加的词条或包内遗漏的词条自动回退到内置 English。格式、限制及模板见同目录的 `语言包格式说明.md` 和 `language-pack.template.json`。界面语言不改变统计口径与北京时间。

### 统计口径

- 使用当前 Codex 登录的 ChatGPT 订阅账户，通过 Codex 自带 app-server 的官方账户接口读取；不发送模型请求，不需要 API key。
- 额度读取 `account/rateLimits/read` 中的 `codex` 桶，按 300 和 10080 分钟识别 5h 与周窗口，剩余比例为 `100 - usedPercent`。
- token 读取 `account/usage/read` 的账户级统计，不传 `threadId`。累计直接采用官方 `lifetimeTokens`，包含服务端记录的账户历史 Codex 用量，包括其他设备；不是本机日志求和，也不是 ChatGPT 普通网页聊天的 token 总量。
- “今日”用北京时间的当前日期查找官方同名日期桶。官方日界时区未公开，不能把它当作精确的北京时间 0:00—24:00 实时统计。每日数据可能延迟：没有今天的桶时显示**尚未更新**，并注明最新日期；只有服务端明确返回 0 才显示 0。
- 官方未提供的数据显示未知；网络故障时保留上次数据，并显示错误和上次更新时间。更换登录账户时清除旧账户的数值。

官方接口说明：[Codex App Server](https://learn.chatgpt.com/docs/app-server#7-token-usage-chatgpt)。

### 开机启动与退出

首次安装默认手动启动；用户可主动设置为随当前 Windows 用户登录自动启动，使用当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `CodexQuotaWidget` 值，不需要管理员权限。可在悬浮条右键菜单或系统托盘 C 图标菜单中取消“随 Windows 登录启动”。

退出：右键悬浮条或系统托盘 C 图标，选择“退出”。退出会同时结束本工具创建的 Codex 后台进程。请保留整个文件夹，移动文件夹后需重新启用自动启动。

也可执行 `CodexQuotaWidget.exe --remove-startup` 移除自动启动，执行 `--install-startup` 重新设置。

### 运行要求与源码

Windows 10/11、.NET 8 Desktop Runtime、已登录的 Codex 桌面应用。安装脚本会检查运行环境；缺少 Desktop Runtime 时提供微软官方下载地址。未在 Windows ARM64 验证。工具不保存或复制登录凭据，不保存聊天内容；Codex 自身负责读取其现有登录状态。

源码包内的 `src/CodexQuotaWidget` 是程序源码；在 Windows 安装 .NET 8 SDK 后，运行仓库的 `scripts/build.ps1`。卸载用包根目录 `widget.ps1 -Action uninstall`，保留 `data` 中的偏好和语言包。

后台只读文件形式的 Codex 登录缓存，不改写主程序配置、登录和会话状态。主程序负责凭据续期；访问凭据过期时请打开 Codex。网络失败会逐步延长重试间隔，成功后恢复每分钟刷新。

## English

### Overview and launch

Codex Quota Widget is a Windows utility deeply tailored to ChatGPT Plus users' Codex workflows. Desktop version: **1.4.7**. The collapsed view uses two chamfered armor panels, with prominent percentages and lighter labels. The expanded view keeps the orange-red main gauge and rounded cards; the two token cards share the same dimensions and typography. Dragging, position memory, and one-click position reset are supported. The default position is at the top center of the primary screen.

Double-click `Start.cmd` in the release package to install and launch, or launch `%LOCALAPPDATA%/CodexQuotaWidget/app/CodexQuotaWidget.exe` after installation. The widget stays above other apps. Its collapsed view shows only the **remaining percentages** for the 5-hour and weekly quotas, plus their respective times: the **5-hour time uses hours and minutes; the weekly time includes month, day, hours, and minutes**. There is no “reset” prefix, logo, Beijing label, decorative light strip, or other explanatory text in that view. All reset times use Beijing time. Hover over a time to see its full value, including year and seconds. The collapsed bar embeds Glow Sans SC / 未来荧黑; percentages use SemiBold, and labels and times use Normal. Percentages are larger and brighter than their labels. Long translations first shrink the label and may then omit it to preserve the percentage; hover to see the full text. No system font installation is needed. The font license is bundled at `Fonts/OFL-GlowSans.txt`.

Hover to expand; moving the pointer away collapses the widget after about **0.28 seconds**. The window's size and position move directly to their target values. Fades and background-layer effects run within that fixed position, avoiding jitter from per-frame native-window resizing. The collapsed view is **270 × 50**, and the expanded view is **584 × 390**, in logical pixels. The expanded view displays quotas, countdowns, reset times, today's tokens, and lifetime tokens. The weekly quota uses its small ring and number without a duplicate bar. Token-card titles, values, and descriptions align with each other; values use the same font size, while “Not updated yet” uses smaller status text.

Each expansion immediately shows the current quota. Smooth value transitions run only when a known quota actually changes. Text stays in a fixed position; pointer parallax affects only background armor and lighting. Decorative arcs move slightly, with subdued breathing light. The sweep runs once per actual refresh. Edge colors indicate refreshing, low quota, or a read error; they are not percentage progress bars. The corresponding edge turns red when the remaining quota is **20% or less**, a display threshold chosen by this tool. Repeating decoration runs only while expanded, stops on collapse, and follows the Windows animation setting. The widget does not automatically take focus from the current app.

Data refreshes once per minute. On a network failure, the previous readings remain visible, with the error and last successful update time at the bottom of the expanded panel and in tooltips. Hover over values to see their full numbers and statistical definitions.

### Move and reset

Hold the left mouse button on the widget's text or background and drag to move it. Refresh, menu, and reset buttons retain normal click behavior. After moving, expansion and collapse remain centered around your selected position rather than returning to the screen center. Near the bottom of the screen, the widget expands upward. Its position is constrained at screen edges to keep it visible. Moving the widget does not take focus from the current app.

Click the upward-arrow button at the top right of the expanded panel to “Restore top center.” The same command is available from the widget and system tray context menus. Double-clicking the widget's text or background also resets it. Resetting returns it to the collapsed state at the top center of the primary screen.

Position is saved in `%LOCALAPPDATA%/CodexQuotaWidget/data/position.json` and restored on the next launch. Resetting clears the saved position. Display-configuration changes constrain the window to an available screen. If the data directory is not writable, dragging and reset still work for that session, but the position is not saved.

### Interface language

Right-click the widget or tray icon and open “语言 / Language” to choose Simplified Chinese, Traditional Chinese, or English. Menus, tooltips, countdowns, status text, and the expanded panel switch immediately. The selected language persists across launches.

Import a JSON file through “Language → Install language pack…” to add another language without recompiling. Installed packs are kept in the user-data `Languages` directory, and language preferences are saved in `settings.json` in the same data directory. Upgrades preserve both, as well as `position.json`. New or missing translation keys fall back to built-in English. See the adjacent `语言包格式说明.md` and `language-pack.template.json` for the format, limits, and template. Interface language does not change the statistical definitions or Beijing time.

### Statistical definitions

- The widget uses the ChatGPT subscription account currently signed in to Codex. It reads official account interfaces through the local Codex app-server, without sending model-generation requests or requiring an API key.
- Quotas come from the `codex` bucket in `account/rateLimits/read`. Windows of **300** and **10080 minutes** identify the 5-hour and weekly limits. Remaining percentage is `100 - usedPercent`.
- Token data uses account-level `account/usage/read`, without a `threadId`. Lifetime usage is the official `lifetimeTokens` value, including account history recorded by the service and usage from other devices. It is not a sum of local logs or the total token usage of ordinary ChatGPT web chats.
- “Today” looks for the official daily bucket whose date label matches the current Beijing date. The service's day-boundary time zone is not documented, so this is not an exact, real-time Beijing-midnight-to-midnight total. Daily reporting may be delayed: if today's bucket is missing, the widget shows **“Not updated yet”** and the latest available date. It displays zero only when the service explicitly returns zero.
- Fields not provided by the service are shown as unknown. On network failure, previous readings remain visible with an error and last update time. Switching the signed-in account clears readings from the previous account.

Upstream interface reference: [Codex App Server](https://learn.chatgpt.com/docs/app-server#7-token-usage-chatgpt).

### Startup and exit

The first installation uses manual startup by default. You can choose to launch the widget when the current Windows user signs in. This uses the `CodexQuotaWidget` value under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`; administrator privileges are not required. Disable “Start with Windows sign-in” from the widget's context menu or the C icon's tray menu.

To quit, right-click the widget or C tray icon and choose “Exit.” This also ends the Codex backend started by this tool. Keep the entire application folder together. If you move that folder, re-enable startup afterward.

You can also run `CodexQuotaWidget.exe --remove-startup` to remove the startup entry, or use `--install-startup` to set it again.

### Requirements, source, and uninstall

Requires Windows 10/11 x64, the .NET 8 Desktop Runtime, and the Codex desktop app with an active login. The tool is tailored to ChatGPT Plus users. The installer checks the environment and provides Microsoft's official download link if the Desktop Runtime is missing. Windows ARM64 has not been verified. The tool does not save or copy login credentials or chat content; Codex is responsible for its existing login state.

Program source is in `src/CodexQuotaWidget` inside the source package. Install the .NET 8 SDK on Windows, then run `scripts/build.ps1` from the repository. To uninstall, run `widget.ps1 -Action uninstall` from the package root. Preferences and language packs under `data` are retained.

The backend reads the file-based Codex login cache without rewriting the desktop app's configuration, login, or sessions. The desktop app renews credentials; open Codex if the access credential expires. Network errors gradually extend the retry interval. After a successful request, refreshing returns to once per minute.
