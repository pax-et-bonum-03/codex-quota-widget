# 语言包格式说明 · Language-pack format

[中文](#中文) · [English](#english)

## 中文

软件内置简体中文、繁體中文和 English。右键悬浮条或系统托盘图标，进入「语言 / Language」切换；选项立即生效，并保存在`%LOCALAPPDATA%/CodexQuotaWidget/data/settings.json`，下次启动自动恢复。

未来新增语言无需重新编译：复制 `language-pack.template.json`，修改 `id`、`displayName`，翻译 `strings` 中的文字，然后通过「语言 → 安装语言包…」导入。安装后自动切换，文件保存在`%LOCALAPPDATA%/CodexQuotaWidget/data/Languages` 文件夹。导入相同 ID 的外部包会更新该语言。

最小示例：

```json
{
  "schemaVersion": 1,
  "id": "de",
  "displayName": "Deutsch",
  "strings": {
    "mini.five": "5h frei {0}",
    "mini.week": "Woche frei {0}"
  }
}
```

- `schemaVersion` 为数字 `1`，用于后续格式兼容。
- `id` 使用 `en`、`de`、`ja-JP` 等语言标识形式；内置的 `zh-CN`、`zh-TW`、`en` 保留，不允许覆盖。
- `displayName` 是语言在菜单中的名称，最多 64 个字符。
- `strings` 是翻译键与纯文本的映射；不要求每个键都提供。遗漏或将来新增的键自动回退到内置 English，避免旧语言包因软件更新失效。保留未知键供未来版本使用。
- 保留原文中的 `{0}`、`{1}` 等变量；可调整顺序，不可增删变量编号。JSON 中用 `\n` 表示换行。
- 文件上限 64 KB、最多 200 个键、单条翻译最多 1600 字符。语言包不执行脚本、不加载程序代码、字体或 XAML。
- 收起条保持固定大小，建议短译文。过长的收起标签会先缩小、再省略，百分比保持原字号；悬停可查看完整译文和时间。保留 `{0}` 一次即可，可放在标签前或后。字体没有覆盖的其他语言会使用 Windows 的字体回退。

界面语言不改变统计口径和时区：额度仍显示剩余百分比，时间仍为北京时间（UTC+8）；收起态 5h 仅 `HH:mm`，周额度为 `MM-dd HH:mm`。

备份设置时保存整个用户 `data` 目录，包括 `settings.json`、`position.json` 和 `Languages`。程序升级、卸载默认保留此目录。

## English

Simplified Chinese, Traditional Chinese, and English are built in. Right-click the widget or system tray icon and open “语言 / Language” to switch languages. The choice takes effect immediately, is saved in `%LOCALAPPDATA%/CodexQuotaWidget/data/settings.json`, and is restored on the next launch.

Adding another language does not require recompiling. Copy `language-pack.template.json`, change `id` and `displayName`, translate the values under `strings`, and import the file through “Language → Install language pack…”. The imported language is selected automatically, and its file is saved under `%LOCALAPPDATA%/CodexQuotaWidget/data/Languages`. Importing an external pack with the same ID updates that language.

Minimal example:

```json
{
  "schemaVersion": 1,
  "id": "de",
  "displayName": "Deutsch",
  "strings": {
    "mini.five": "5h frei {0}",
    "mini.week": "Woche frei {0}"
  }
}
```

- `schemaVersion` must be the number `1`, reserved for future format compatibility.
- `id` uses a language identifier such as `de` or `ja-JP`. The built-in IDs `zh-CN`, `zh-TW`, and `en` are reserved and cannot be replaced.
- `displayName` is the name shown in the menu and may contain up to 64 characters.
- `strings` maps translation keys to plain text. Not every key is required. Missing or newly added keys fall back to built-in English so older packs remain usable after an update. Unknown keys are retained for future versions.
- Preserve placeholders such as `{0}` and `{1}`. Their order may change, but their numbers must not be added or removed. Use `\n` for a newline in JSON.
- A file may be at most 64 KB, contain at most 200 keys, and use at most 1,600 characters per translation. Language packs do not execute scripts or load program code, fonts, or XAML.
- The collapsed bar has a fixed size, so short translations work best. Long labels first shrink and may then be omitted; the percentage retains its font size. Hover to see full translations and times. Include `{0}` exactly once in each collapsed label, before or after its text. Languages not covered by the embedded font use Windows font fallback.

Changing the interface language does not change the statistical definitions or time zone. Quotas still show remaining percentages, and times use Beijing time (UTC+8). In the collapsed view, the 5-hour window uses `HH:mm`; the weekly window uses `MM-dd HH:mm`.

To back up preferences, keep the entire user `data` directory, including `settings.json`, `position.json`, and `Languages`. Upgrades and uninstallation preserve this directory by default.
